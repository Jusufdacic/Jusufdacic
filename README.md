## 📌 Projects

**[SportBook](https://github.com/Jusufdacic/sportbook)**
A full-stack sports facility booking platform. ASP.NET Core REST API with JWT authentication, role-based authorization and BCrypt password hashing, backed by SQL Server through Entity Framework Core, paired with a Flutter mobile client. Users book courts, rent equipment and leave reviews; administrators generate time slots, block courts, and scan reservation QR codes for on-site check-in.

**[JavaScript Fundamentals](https://github.com/Jusufdacic/javascript-fundamentals)**
Algorithmic problem-solving, DOM manipulation and REST API integration exercises in vanilla JavaScript — including a solved Trapping Rain Water (LeetCode Hard), Mastermind scoring logic that handles repeated digits, and a full CRUD client built on `fetch`.
